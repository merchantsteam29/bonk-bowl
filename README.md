# Bonk Bowl

3-player party game on one keyboard. Dash into your friends and bonk them off a crumbling hex arena. Last blob standing wins.

**Play:** https://merchantsteam29.github.io/bonk-bowl/

| Player | Move | Dash |
| --- | --- | --- |
| RED | W A S D | Q |
| BLUE | I J K L | U |
| GOLD | Arrow keys | Enter / Numpad 0 |

Controllers work too (press A to join). Empty slots can be filled with CPU players.
Pickups: **MEGA** (huge and heavy), **ZOOM** (fast, quick dashes), **QUAKE** (shockwave).

Run locally: `node serve.js` then open http://localhost:8080
